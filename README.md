## 🌐 Publicación en GitHub Pages (Paso a Paso)

Este proyecto está 100% optimizado para ejecutarse como un sitio estático ultra-rápido en **GitHub Pages** sin requerir builds complejos:

1. **Inicializar Git y subir a GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit portfolio Cristian Delgadillo"
   git branch -M main
   git remote add origin https://github.com/labrujasiete/NOMBRE_DEL_REPO.git
   git push -u origin main
   ```

2. **Habilitar GitHub Pages**:
   - Ve a tu repositorio en GitHub: **Settings** -> **Pages**.
   - En **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main` / `/ (root)`
   - Guarda los cambios. Tu sitio estará disponible en minutos en:
     `https://labrujasiete.github.io/NOMBRE_DEL_REPO/`

## 💻 Vista Previa Local

Para ver el sitio localmente en tu navegador:
- Simplemente abre el archivo `index.html` en cualquier navegador web moderno, o
- Ejecuta un servidor local:
  ```bash

  # o con npx
  npx serve .
  ```
